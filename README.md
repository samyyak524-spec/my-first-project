# KRISHIMITRA AI

Production-grade scaffold for an AI-powered Indian farming super app:
- Flutter frontend (Riverpod + GoRouter + Material 3)
- FastAPI backend (modular routers + AI services)
- Firebase auth integration pattern
- PostgreSQL + Firestore data architecture
- Dockerized local deployment

See:
- `frontend/` for Flutter app
- `backend/` for FastAPI services
- `infra/` for docker compose and deployment materials
